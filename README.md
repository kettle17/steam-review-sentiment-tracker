# Steam Review Sentiment Tracker

This project will grab Steam reviews from games using the Steam API and examine reviews.
Steam has a positive and negative review system with no in-between.
This leads to some ambiguity and also some neutral reviews being labeled as positive.
This sentiment tracker will show the most prevailing sentiment towards a game in both reviews along with a true % rate of positive/neutral/negative.
This will be done by examining sentiment in keywords in both types of reviews to see what they actually reflect.
